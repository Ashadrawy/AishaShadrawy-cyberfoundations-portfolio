## Analysis Questions

Answer each question in your own words. These questions connect what you did in Parts A and B to the bigger picture of this course.

### Analysis Question 1

If the operating system crashed on the computer you diagrammed, which layer(s) would stop working, and which (if any) would keep working? Explain your reasoning.

```
The operating system is the middle man. If the operating system does not work then neither will the software. The hardware will still be present and have the data/item already stored, but there would be no way to remove the items/data without a functioning operating system.
```

### Analysis Question 2

Pick one piece of software you use daily. Trace it down through the OS to the hardware it ultimately depends on. What would happen to that software if the hardware layer failed?

```
If the hardware failed, there would be no way to access the operating system. The operating system functions off of the hardware and what it is capable of doing or not.
```

### Analysis Question 3

Explain, in your own words, why a cybersecurity professional needs to understand all three layers — hardware, OS, and software — rather than just the software layer where most visible attacks (like phishing emails) happen.

```
To know where the attacks is coming from, you have to know how the system as whole works. They could miss something, if they were unaware how the bottom layer works with the top or the middle layer. They need to be able to recognize where an attack starts, travels, and stops. 
```
